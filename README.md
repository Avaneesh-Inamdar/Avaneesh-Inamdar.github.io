# Avaneesh Inamdar

Personal portfolio: **https://avaneesh-inamdar.github.io/**

Static HTML, CSS, and JavaScript, hosted on GitHub Pages. No build dependencies, server, database, or Azure credit required.

## Editing

- `index.html` — portfolio content and project links
- `styles.css` — layout and responsive styling
- `script.js` — mobile navigation, project notes, and email copying
- `assets/` — local font, project screenshots, and resume

Push changes to `main` to publish the updated site. The `.nojekyll` file keeps the site as plain static files.

To preview locally, run `python -m http.server 4173` in this directory.
